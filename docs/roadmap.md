# 观命开发路线图

## Phase 0: 项目骨架

- 初始化 Git 仓库
- 创建 `dev/software` 开发分支
- 完成产品定位、MVP 范围和路线图

## Phase 1: 网页 App 原型

目标：做出可点击、可体验的前端 MVP。

功能：

- 出生信息录入页
- 首页每日洞察
- 本人命盘分析页
- AI 命盘教练对话页
- 本地 mock 数据

建议技术：

- React 或 Next.js
- TypeScript
- Tailwind CSS
- 本地 JSON mock 数据

## Phase 2: AI 报告生成

目标：从静态 mock 变成真实 AI 生成。

功能：

- 用户资料保存
- AI 生成本命分析
- AI 生成每日洞察
- AI 命盘教练问答
- 报告结构化输出

## Phase 3: 排盘算法接入

目标：让命理输入从 AI 猜测变成真实排盘数据。

优先级：

1. 八字排盘
2. 紫微斗数排盘
3. 流年、流月、流日
4. 星盘与合盘

## Phase 4: 会员与增长

可能功能：

- 深度报告
- 年度运势
- 情感合盘
- 关系建议
- 付费解锁
- 分享卡片

## 推荐 MVP 顺序

1. 先做前端体验，验证用户是否喜欢“每日命盘教练”。
2. 再接 AI 生成报告，验证内容吸引力和留存。
3. 最后接真实排盘，提升专业可信度。
