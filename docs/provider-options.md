# 第三方排盘 API 与自研路线

## 推荐优先级

### 1. ApiWorks 星图

适合作为第一阶段第三方排盘服务。

已公开能力包括：

- 星盘计算
- 关系匹配分析
- 趋势洞察
- AI 内容能力
- RESTful API
- Python / NodeJS / Java SDK
- 文档、Token、配额和控制台

从公开 SDK 描述看，它覆盖：

- 星盘本命盘、行运盘、比较盘、组合盘
- 紫微斗数排盘
- 八字命盘、流盘、合盘
- 周运、年运、合盘、财运等 AI 报告

适合我们当前阶段：先快速接入，验证产品体验。

### 2. Swiss Ephemeris

适合自研西洋星盘核心计算。

优点：

- 行星位置精度高
- 被大量占星软件使用
- 支持很长时间范围
- 可用于本命盘、行运、相位等计算

注意：

- 商业闭源产品需要关注授权。
- 只解决天文位置计算，不直接给心理/关系解释。

### 3. lunar-python / 6tail 日历库

适合自研八字的底层历法与干支能力。

优点：

- 支持公历、农历、节气、干支、生肖、八字、五行、十神等。
- 无第三方依赖。
- 可作为八字排盘第一版基础。

注意：

- 需要我们自己补十神分析、强弱判断、用神策略、大运流年解释模型。

## 测测的定位

测测可以作为产品参考或商务合作对象，但不建议未经授权直接抓取 App、网页或截图。

原因：

- 技术稳定性差。
- 可能违反平台服务条款。
- 出生信息属于敏感个人资料，必须明确用户授权和数据流向。
- AI 解读需要结构化字段，截图识别不适合长期产品。

## 观命建议方案

### Phase 1：第三方 API 快速接入

用 ApiWorks 或类似服务生成：

- 紫微盘
- 八字盘
- 星盘

观命负责：

- 出生资料录入体验
- 三盘结构化展示
- AI 本人命盘分析
- 每日洞察
- AI 命盘教练

### Phase 2：自研八字

先自研八字，因为八字规则相对更可控。

最小范围：

- 四柱
- 日主
- 五行数量
- 十神
- 纳音
- 大运起运
- 流年

### Phase 3：自研星盘

使用 Swiss Ephemeris 或类似天文历库。

最小范围：

- 太阳、月亮、上升
- 水金火木土
- 十二宫
- 主要相位
- 情感合盘：月亮、金星、火星、七宫、五宫

### Phase 4：紫微自研或继续 API

紫微斗数体系复杂，建议最后处理。

最小范围：

- 命宫、身宫
- 十二宫
- 十四主星
- 四化
- 大限、流年

## 技术接口建议

不管用哪一家 API，前端和 AI 层都只认统一数据结构：

```text
BirthProfile -> ChartProvider -> ChartBundle -> AIReport
```

这样后面从第三方 API 切换到自研排盘时，不需要重写页面和 AI 逻辑。
