# 观命

观命是一个以东方命盘为底层语言的每日自我洞察网页 App。

第一版定位为 AI 报告原型：用户输入出生年月日、出生分钟、出生地和性别后，系统生成本人命盘分析、每日洞察和 AI 命盘教练建议。紫微斗数与八字作为产品灵魂，西洋星盘先作为后续情感合盘模块的辅助体系。

## 产品方向

- 面向普通用户，而不是专业命理师。
- 目标不是简单判断吉凶，而是帮助用户理解自己，并知道接下来怎么做。
- 气质偏东方神秘感，但表达要克制、清晰、可行动。
- AI 的角色是人生教练，输出命理解释、现实提醒和每日行动建议。

## MVP 模块

1. 本人命盘分析
   - 核心人格驱动力
   - 天赋资源
   - 消耗模式
   - 事业与财富倾向
   - 感情模式
   - 人生主线与修行课题

2. 每日洞察
   - 每日一句
   - 今日运势
   - 命盘能量图
   - 今日适合与不宜
   - 今日行动建议

3. AI 命盘教练
   - 用户围绕事业、关系、情绪、财富和人生选择提问
   - AI 基于用户命盘画像给出解释与建议

## 后续模块

- 紫微斗数排盘引擎
- 八字排盘引擎
- 西洋星盘与情感合盘
- 流年、流月、流日时间线
- 会员报告与深度咨询
